# Animation source backup

This archive preserves every existing animation sheet, preview strip, portrait, ASCII frame collection, source manifest, attribution and license, plus the matching portrait/preview generators and playback components. It contains no user data or engine credentials.

The application now enables the 21 Fate chibi characters by default. The other 55 catalog entries remain archived and may be re-enabled with the authenticated avatar catalog API. Legacy aliases remain compatible. Disabling a selection never deletes an employee, native session, working directory or message.

`manifest.json` lists every original file and SHA-256. Extract `animation-sources.tar.gz` into a separate folder to inspect this pre-rework snapshot. Current application assets remain available for live reactivation. Existing provenance and redistribution-review statements are preserved; this backup does not assert new permissions.
