# Message 工作台

Message 将资讯阅读、私聊、群组与交付放在同一个工作环境中。主会话保留独立头像、柔和的背景与悬浮标题栏；资料、权限、订阅和配置使用统一的工作面，不因入口不同随机变成另一套侧栏或弹窗。

## 清楚的操作范围

- **阅读与讨论**：频道提供 Channel、Board、Posts；私聊与群组支持引用、讨论串、图文混排、投票和清单。Posts 缩放独立保存，不改变导航宽度或其他视图。
- **资料与设置**：共同的标题、返回按钮、分区导航和固定操作栏。群资料、成员权限、邀请、治理、公告、历史恢复各有明确分区；订阅列表、频道资料、进程部署和连接凭据分别展示。
- **文件**：一个共享文件入口提供搜索、排序、预览、上传、新建文本、编辑、重命名与可恢复删除。PDF 直接交给 Margin Reader，图片使用完整查看器。加入群组不会新增员工工作区；员工始终使用 Team 分配的目录。
- **外部 Bot**：主目录直接展示 Dot、Grok 的全部 Bot 与原生群组，可搜索、直接打开和进入对应设置；数量栏与管理器都显示账户总数，已接入项目不会重复出现。管理器提供原生资料、群成员及平台支持的运行控制。原生账户设置、Aexus 别名与员工授权各自清楚标明；离线缓存不会显示成已同步。
- **简短操作**：重命名等短表单使用同样的标题和操作位置，以紧凑尺寸呈现。上下文菜单、下拉选择、媒体查看器和确认提示按内容采用合适的形式，不再承担庞杂的设置页面。

左侧 Category 保留切换高亮动画；会话、频道来源与 Channel/Board/Posts 选中状态在原位更新。隐藏窗口与减少动态效果设置会关闭非必要播放。

私聊与群聊的长文、结构化内容和图文报告共用最大 880px 的阅读宽度，随可用空间收缩；简短回复、表情和贴纸保留紧凑尺寸。附图本身不会把长报告挤成窄列。消息菜单、头像、引用和回执仍沿用原消息身份。

私聊和群聊的气泡使用连续的圆角与曲线尾角，朝向消息作者的头像；连续同作者消息只在末条显示尾角，表情和贴纸保持透明背景。尾角与正文共用颜色、边线和同一段进场动画，不占据额外布局空间；分组变化只淡出尾角，不移动历史消息。

发送区统一圆角、间距、焦点和按钮反馈；多行输入在有限时间内平滑调整高度，尊重减少动态效果设置。输入法组字不触发发送，Shift+Enter 换行。已确认接收的原稿立即退出输入框，草稿的条件清理继续在后台完成，较新的输入不会被旧请求覆盖。群聊完成发送前的持久化后即可继续编写下一条草稿，发送按钮仍保留当前请求的状态与去重保护。

新消息使用短距离、有限时长的进场动画，不晃动背景，也不把长报告大幅拉伸。消息正文更新、打开历史、恢复消息和向上翻页不重播进场动画；阅读旧消息时的新内容不会拉走当前位置。虚拟列表会等待新行实际挂载后再播放。

## 阅读位置

角色私聊、群聊及群话题分别记住阅读位置。离开后回来会恢复到同一条消息内的原位置，旧消息页按需加载；如果离开时在底部，回来继续跟随最新消息。明确点击引用或搜索结果时，目标定位优先。当前客户端刷新后也会保留位置，恢复旧阅读位置不会把尚未看到的新消息标为已读。

阅读位置只保存消息 ID、视口偏移和跟随模式，独立保存在当前客户端，不写入员工上下文或共享工作区。消息已撤回时显示其原位置的提示；定位已失效时回到可用历史。

## 草稿与并发

设置会清楚区分即时生效与需要保存的修改。返回或切换前处理未保存内容；明确的取消、保留草稿、放弃与保存不会混为一个动作。提交失败后，键盘导航和 Escape 仍作用于当前工作面。转发保留稳定请求身份与结果查询；未知送达结果不自动重发，已发送但导航失败也不会重新发送。

文本编辑使用 Core 返回的内容 hash；遇到并发修改保留输入，明确放弃后才重新加载。文件重命名可携带不透明版本，拒绝同名覆盖并维护当前/可恢复消息的附件路径。原消息正文、作者、任务与回执保持原样。文件上传进入共享资料，不隐式向群组发布新消息；发送文件仍通过会话输入框明确确认。

所有业务行为继续通过同一套认证 Core、CLI 和 API。界面不会通过目录名称、当前视图或组件状态提升权限、改变执行主机或重建原生会话。原生 Bot 使用自身协议支持的能力，连接别名、Aexus 授权与原生资料分别管理。

## 验证入口

`npm run test:message-workspaces` 使用临时数据目录验证文件重命名与消息引用，以及实际工作面中的保存、冲突、授权、邀请、配置、订阅、分类、群组创建和多主题布局。桌面测试保持窗口隐藏，Web 使用无头浏览器。原七项阅读/头像/动画要求、转发恢复和群协作另有专门的回归检查；实际通过范围和未测试平台应以对应验证报告为准。

`node test/message-surface-web-test.mjs`（桌面加 `--desktop`）验证相同长文的纯文字、内联图片与附图宽度，窄窗口、输入法、连续输入、延迟与失败、角色发布的私聊回复，以及超过 200 条历史时的进场和阅读位置。`test/messenger-draft-recovery-ui-test.mjs` 继续验证跨客户端替换、条件清理、晚到响应和私聊/工作区草稿隔离。

`node test/message-reading-position-ui-test.mjs`（桌面加 `--desktop`）验证独立会话、消息内偏移、跨分页恢复、新消息与未读、刷新、主视图切换、底部跟随和失效定位回退。
